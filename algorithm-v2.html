数学预警模型 · 第二版技术文档

版本：v2（第二版）
算法名称：传感器标定对齐 + 快速滑动基准预警模型

一、v2 相对 v1 的改动

项目v1v2原因
预警等级命名1=三级 / 3=一级0=正常 / 1=一级 / 2=二级 / 3=三级等级体系规范：数字越大越严重

二、算法结构

最终等级 = max(泥石流 D, 山洪 F, 风速, 流量尖峰, 突变, 土壤饱和) ← 0~3
等级含义触发示例
0正常各因子均低于阈值
1一级预警（最轻）D/F ≥ 0.45，或风速 ≥25 km/h
2二级预警D/F ≥ 0.55，或风速 ≥40 km/h
3三级预警（最严重）D/F ≥ 0.75，或风速 ≥60 km/h

1. 泥石流路径

D = 0.30 × S̄ + 0.35 × Q̄ + 0.20 × dQ̄ + 0.15 × ΔS̄

土壤 <60% 时跳过（山洪/风速不受限）。

2. 山洪路径（独立指数）

F = 0.60 × Q̄ + 0.40 × dQ̄

不受土壤门槛限制，流量暴涨即触发。

3. 风速路径

≥25 km/h → 一级；≥40 km/h → 二级；≥60 km/h → 三级。

4. 流量尖峰路径

秒级变化率超当地历史 P95 → 二级；≥0.8 归一化 → 一级。

5. 突变路径（秒级响应）

土壤 5 秒内涨 ≥20% / 风速 60 秒内涨 ≥12 km/h → 立即一级。

6. 土壤饱和路径（v2 新增）

土壤 ≥85% 或超当地 P90 → 至少一级（不依赖流量）。

7. 滞回保持（v2 新增，防抖）

升级立即生效；降级需超过保持时间 —— 一级 10 秒 / 二级 15 秒 / 三级 20 秒。

三、LCD 显示（v2 新增）

W12.3 S45% F0.50 ← 风速 km/h · 土湿度 % · 水流速 L/min ALARM:3 L3 ← 预警等级 0~3（0=正常，3=三级最严重）

四、优势

  • 流量数据真正参与推理：标定参数对齐传感器量程后，Q̄/dQ̄ 变成有效因子
  • 滑动基准快速启用：15 分钟冷启动
  • 等级体系规范：0~3 数字越大越严重
  • 现场可视化：LCD 实时显示四路核心数据
  • 诊断能力：脉冲双向沿计数 + 电平输出

五、缺陷

  • 流量计量程仍窄（YF-S401 仅 0.05~3 L/min）
  • 风速数据依赖外部电脑（192.168.1.200:8001）
  • 滑动基准 15 分钟仍可能不够稳
  • 突变阈值仍是经验值
  • LCD 仅 ASCII，无法显示中文
